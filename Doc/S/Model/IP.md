Ti=Intellectual Property Model Agreements and Licenses

Note=IP model agreements span open source licenses, technology transfer, patent licensing, and contributor agreements. Creative Commons dominates open content; SPDX provides machine-readable license identifiers; WIPO provides resources for technology transfer. Several of these are codified in G/.

=Open Source Software Licenses

SPDX=<a href="https://spdx.org/licenses/">https://spdx.org/licenses/</a> /// Software Package Data Exchange. Canonical list of open source licenses with machine-readable identifiers. The authoritative index of OSI-approved and other common licenses.

OSI=<a href="https://opensource.org/licenses">https://opensource.org/licenses</a> /// Open Source Initiative. Approves and maintains the list of OSI-certified open source licenses.

ChooseALicense=<a href="https://choosealicense.com/">https://choosealicense.com/</a> /// GitHub's plain-language license chooser. Explains MIT, Apache, GPL, and others.

Polyform=<a href="https://polyformproject.org/">https://polyformproject.org/</a> /// Polyform Project. Source-available license family (Noncommercial, Small Business, Perimeter, Shield, Strict, Free Trial, Internal Use).

=Open Content

CreativeCommons=<a href="https://creativecommons.org/licenses/">https://creativecommons.org/licenses/</a> /// Creative Commons. BY, BY-SA, BY-NC, BY-NC-SA, BY-ND, BY-NC-ND license family. Version 4.0 is the current standard. CC0 for public domain dedication.

=Open Hardware

CERN-OHL=<a href="https://cern-ohl.web.cern.ch/">https://cern-ohl.web.cern.ch/</a> /// CERN Open Hardware Licence family (Permissive, Weakly Reciprocal, Strongly Reciprocal). Version 2.0. The standard for open hardware projects.

=Patent Licensing

WIPO-TechTransfer=<a href="https://www.wipo.int/amc/en/center/specific-sectors/rd/ipag/">https://www.wipo.int/amc/en/center/specific-sectors/rd/ipag/</a> /// WIPO IPAG Model Agreements for R&D and technology transfer. Includes licensing, research collaboration, and joint development templates.

WIPO=<a href="https://www.wipo.int/web/technology-transfer">https://www.wipo.int/web/technology-transfer</a> /// WIPO Technology Transfer hub. Model contracts, guides, negotiation tools.

DPL=<a href="https://defensivepatentlicense.org/">https://defensivepatentlicense.org/</a> /// Defensive Patent License. Reciprocal patent license creating a defensive patent pool. Signatories grant each other royalty-free licenses.

CreativeCommons-Patent=<a href="https://wiki.creativecommons.org/wiki/Model_Patent_License">https://wiki.creativecommons.org/wiki/Model_Patent_License</a> /// Creative Commons Model Patent License. Framework for patent licensing compatible with open content.

=Contributor Agreements

ContributorAgreements=<a href="https://contributoragreements.org/">https://contributoragreements.org/</a> /// ContributorAgreements.org. Model CLAs for open source projects — individual and entity variants. Maintained by the Free Software Foundation Europe and others.

Harmony=<a href="https://www.harmonyagreements.org/agreements">https://www.harmonyagreements.org/agreements</a> /// Harmony Agreements. Standardized contributor license and assignment agreements for open source projects.

=Technology Transfer (University / Research)

AUTM=<a href="https://autm.net/surveys-and-tools/agreements">https://autm.net/surveys-and-tools/agreements</a> /// Association of University Technology Managers. Model agreements for university technology transfer, MTAs, and sponsored research.

UBMTA=<a href="https://autm.net/surveys-and-tools/agreements/material-transfer-agreements/mta-guiding-principles">https://autm.net/surveys-and-tools/agreements/material-transfer-agreements/mta-guiding-principles</a> /// Uniform Biological Material Transfer Agreement. NIH/AUTM standard for biological material transfers between research institutions.
